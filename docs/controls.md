# Controls

Keyboard shortcuts act on the 3D view when it has focus; typing in a field leaves editor shortcuts inactive. In the app, **Help › Keyboard shortcuts…** (or `?`) opens a searchable version of this list.

## Camera (every 3D view)

| Action | Keys |
|---|---|
| Fly | W A S D, Q / E down / up, Shift faster (viewport focused) |
| Orbit / pan / zoom | Middle drag or Alt + left drag / right drag / wheel |
| Keyboard orbit | Arrow keys while held (Left / Right turn, Up / Down tilt, Shift faster) |
| Orbit in steps | Numpad 4 / 6 / 8 / 2 in 15° steps · Numpad 9 opposite side · Numpad + / − zoom |
| Views | Numpad 1 front · 3 right · 7 top · 5 orthographic; with Ctrl: back · left · bottom |
| Frame selected / frame all | F / Home |
| Shading | Z cycles textured, solid, wire, X-ray |
| Lighting | Baked · Studio · Unlit in the header |
| Backdrop | Image icon in the activity bar (dark or blueprint grid) |

**Lighting.** *Baked* (the default) draws a model's baked vertex colours as the game does and lights models that have none with the scene lights. *Studio* lights everything with an ambient fill and a key light from the camera, ignoring baked colours (useful on night maps). *Unlit* shows textures at full brightness.

## Map Builder

| Action | Keys |
|---|---|
| Tools | V select · G move · R rotate · T scale · P place · B paint clutter (Ctrl erases) · M measure |
| Select | Click · Shift+click adds · Ctrl+click removes · drag for a box · Shift+A selects the same model |
| Duplicate / delete / drop to ground | Shift+D / X or Delete / End |
| Copy / paste clutter | Ctrl+C / Ctrl+V (also into another package that has the model) |
| Hide / isolate / show all | H / Shift+H / Alt+H |
| Walk mode | Shift+F; W A S D walk, Shift runs, Esc stops |
| Minimap | N (wheel zooms, click moves the view) |
| Open the selected prop in the Model Editor | Double-click |
| Cancel placement | Escape |

## Model Editor

| Action | Keys |
|---|---|
| Selection mode | 1 object · 2 visual · 3 chunk · 4 vertex · 5 face |
| Tools | Q select · G move · R rotate · S scale · P vertex paint · B weight paint · T texture paint |
| Inset faces | I |
| Duplicate / delete faces | Shift+D / X |

## Animation Editor

| Action | Keys |
|---|---|

## Asset Viewer

| Action | Keys |
|---|---|
| Open | Double-click or Enter |
| Up / back / forward | Backspace / Alt+Left / Alt+Right |
| Move the selection | Arrow keys |
| Play a clip | Space |
